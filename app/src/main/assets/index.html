편안한 읽기

오프라인 낭독에는 기기에 한국어 오프라인 음성이 설치되어 있어야 합니다. 설치하거나 기본 음성 엔진을 변경한 뒤 ‘한국어 음성 다시 확인’을 누르십시오. 오프라인 여부는 비행기 모드에서 확인할 수 있습니다. 일시정지 후 재생하면 현재 문단의 처음부터 읽습니다.

전문용어 발음사전

한 줄에 ‘원문=읽을 소리’를 입력합니다.
본문은 그대로 두고 낭독할 때만 적용합니다.

본문 검색

알아차림 전자책 1.0

‘책 열기’에서 파일을 선택하면 앱 안에 복사하여 보관합니다. 가로 화면에서는 책장·목차와 본문을 함께, 세로 화면에서는 본문을 넓게 표시합니다.

본문 문단을 누른 뒤 낭독을 시작하십시오. ☆로 책갈피를 저장하고, 왼쪽 책갈피 목록에서 다시 찾아갑니다. 읽기 위치는 자동 저장됩니다.

TXT: UTF-8·UTF-16·CP949 지원.
EPUB: DRM 없는 본문을 읽기 순서대로 표시.
DOCX: 문단·표 안의 텍스트를 읽는 순서로 표시.
PDF: 원본 페이지 보기와 추출한 텍스트 읽기.

EPUB·DOCX의 삽화·복잡한 표·원래 지면은 재현하지 않습니다. PDF의 다단 편집은 추출 순서가 원본과 다를 수 있습니다. 스캔 PDF는 원본 보기가 가능하지만 OCR·검색·낭독은 지원하지 않습니다. 암호화 문서는 지원하지 않습니다.

파일당 최대 50MB, 추출 본문 최대 500만 자입니다. 앱을 삭제하면 가져온 책·책갈피·사전도 삭제됩니다. 원본 파일은 별도로 보관하십시오.

낭독 중 다른 앱으로 이동하거나 화면을 잠그면 일시정지됩니다. 앱은 인터넷 권한을 요청하지 않습니다.
