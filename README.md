# 알아차림 전자책 · MindfulEBook

Android 태블릿에서 TXT·EPUB·PDF·DOCX를 기기에 보관하고 한국어로 읽고 듣는 전자책 앱입니다. 앱 자체에는 인터넷 권한·광고·서버 전송 기능이 없습니다.

## 사용 환경

- Android 8.0(API 26) 이상. 태블릿 가로/세로 화면 자동 재배치.
- 한국어 TTS는 기기의 **오프라인 한국어 음성**을 설치한 뒤 사용합니다.
- 앱 내 `가 Aa → 기기 음성 설정`에서 엔진 설정을 열 수 있습니다. 음성 설치 또는 엔진 변경 후 `한국어 음성 다시 확인`을 누르십시오.
- 제조사 TTS가 오프라인 여부를 명확히 보고하지 않을 수 있으므로, 최초 사용 시 비행기 모드에서 한국어 낭독을 확인하십시오.

## 구현 기능

- 가로: 왼쪽 책장·목차·책갈피, 오른쪽 본문. 세로: 본문 중심 + 접이식 책장.
- 시스템 파일 선택기로 문서 가져오기, 앱 내부 복사본으로 오프라인 읽기.
- TXT: UTF-8, UTF-16 BOM, CP949. EPUB: OPF spine 순서의 텍스트와 구역 목차. DOCX: 문단·표 셀 텍스트, Heading 스타일 목차.
- PDF: 페이지별 텍스트 추출, 원본 페이지 렌더링, 100–250% 확대, 페이지 이동.
- 본문 검색, 문단 이동, 읽기 진행률, 책갈피, 읽던 문단/PDF 페이지 자동 저장.
- 한국어 오프라인 TTS, 재생·일시정지, 이전·다음 문단, 0.7–1.5배 속도.
- 전문용어 발음사전: 한 줄당 `원문=발음`, 긴 용어 우선 적용, 변환 결과를 다시 변환하지 않음.
- 글자 크기 16–36px, 줄 간격 1.4–2.4배, 밝은 화면·세피아·다크 모드.
- 50개 문단 단위 렌더링으로 긴 책의 화면 부하 제한. 끝의 ‘다음 본문 이어 읽기’로 계속 읽기. 낭독 시 자동 연결.

## 지원 범위와 제한

- EPUB·DOCX는 텍스트 중심 리플로 보기입니다. 삽화·각주 연결·복잡한 표·원본 지면은 보존하지 않습니다.
- DRM·암호화 문서, DTD 포함 구성 XML은 지원하지 않습니다.
- 스캔 PDF는 원본 보기가 가능하지만 **OCR을 포함하지 않아 텍스트 검색·낭독이 불가능**합니다. PDF 다단 문서의 추출 순서는 원본과 다를 수 있습니다.
- 파일당 50MB, 본문 500만 자, PDF 3,000쪽까지입니다.
- 일시정지 후 현재 문단 처음부터 다시 읽습니다. 다른 앱 이동·화면 잠금 시 낭독이 일시정지됩니다. 백그라운드 재생은 포함하지 않습니다.
- 앱 삭제 시 앱 내부 책·위치·책갈피·사전이 삭제됩니다. 원본 문서는 별도로 보관하십시오.
- 이번 APK는 직접 설치용 **개발 서명 검증판**입니다. Play Store 배포판이 아닙니다. 다른 서명으로 만든 APK를 덮어 설치할 수 없습니다. 업데이트 배포에는 동일 서명키 유지가 필요합니다.

## 빌드

JDK 17, Android SDK 35, Gradle 8.9:

```sh
gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
GitHub Actions의 `Android APK` 워크플로에서도 빌드하며 성공한 실행의 Artifacts에서 내려받을 수 있습니다. CI에서 만든 개발 서명 APK는 이 대화에서 제공하는 APK와 서명이 다를 수 있습니다.

## 구조

- `MainActivity.java`: 기기 파일 선택, 내부 저장, TTS·오디오 포커스, PDF 원본 렌더링, WebView 연결.
- `BookParser.java`: 제한된 ZIP/XML 처리, TXT·EPUB·DOCX·PDF 텍스트 추출.
- `TextTools.java`: 문자 인코딩, 낭독 문단 분할, 발음 치환, ZIP 상대경로 검사.
- `assets/reader.*`: 로컬 전용 반응형 화면과 읽기 상태.
- 가져온 문서 내용은 HTML 실행 없이 textContent로 표시합니다. 웹 탐색과 네트워크 권한을 허용하지 않습니다.

검증 내용은 `VALIDATION.md`, 외부 라이선스는 `THIRD_PARTY_NOTICES.md`를 참조하십시오.
